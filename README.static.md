# Air 2 interactive H5 demo

The prototype uses exact 402×874 renders of the source Figma frames. Transparent hotspots reproduce the documented flow without restyling the screens.

Run locally with `python3 -m http.server 4173 --directory air2-h5-demo`.

Flow: Device → Breast Pump subhome → manual control → Fit Check → manual stimulation → Auto Switch → expression → program list → Milk Boost → stop → log pumping amount → logged confirmation.
